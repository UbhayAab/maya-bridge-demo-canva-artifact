# Maya and the Tiny Bridge Canva Artifacts

Public artifact repository used so Canva can import prototype PDFs by HTTPS URL.

The original `maya_and_the_tiny_bridge_canva_import_spreads.pdf` is the earlier layout proof. The `chatgpt_stage_boards/` folder contains the current four-stage prototype boards generated through the logged-in ChatGPT web interface:

1. `01_character_object_sheet_canva.pdf` - character and recurring object consistency sheet.
2. `02_reference_camera_board_canva.pdf` - reference, camera angle, perspective, composition, and mood board.
3. `03_stencil_storyboard_canva.pdf` - black-and-white stencil/storyboard pass with the correct characters.
4. `04_final_color_board_canva.pdf` - colored final output board with five finished panels.

Generated by the illustrated-book-content-engine prototype.
