# Maya and the Tiny Bridge Canva Artifacts

Public artifact repository used so Canva can import prototype PDFs by HTTPS URL.

## Current Scene-Level Package

`scene_level_final_book/` contains the current generated files from the content engine:

1. `maya_and_the_tiny_bridge_scene_level_final_spreads.pdf` - three Canva spreads for the five-page demo book, with all 15 derived scenes placed into page/spread panels.
2. `stage_files/01_character_object_sheets.pdf` - separate character and recurring object consistency sheet.
3. `stage_files/02_reference_camera_boards.pdf` - one reference/camera/perspective card per derived scene.
4. `stage_files/03_stencil_boards.pdf` - one stencil-production card per derived scene.
5. `stage_files/04_final_color_boards.pdf` - one final-color planning card per derived scene.
6. `canva_manifest.json` and `stage_manifest.json` - machine-readable import manifests.

These files are generated from the story text and scene-plan metadata. The scene count is not hardcoded; the current demo resolves to 15 scenes across 5 story pages.

The current engine also emits spatial-model contracts, recurring-room camera references, and decal-lock manifests in the main repository. Those files are used before final art generation to keep repeated workshops, vehicles, signs, menu prices, windows, tables, and other fixed elements consistent.
