# Zoya and the Wind Garden Canva Artifacts

Scene-level Canva import package for the 10-page engineer-and-kid prototype.

## Files

- `zoya_and_the_wind_garden_final_spreads.pdf` - final 10-page book assembled as 5 spreads.
- `canva_scene_files/01_detailed_scene_story.pdf` - 27 scene-level pages with story, assets, camera, and final visual.
- `canva_scene_files/02_character_asset_sheets.pdf` - all characters and recurring assets, one per page.
- `canva_scene_files/03_scene_setup_camera_references.pdf` - one scene per page with camera/reference image and setup image.
- `canva_scene_files/04_stencil_scenes.pdf` - one black-and-white stencil page per scene.
- `canva_scene_files/05_final_color_scenes.pdf` - one colored final page per scene.

The source story is 10 pages. The production files are scene-level, so the scene files have 27 pages.
